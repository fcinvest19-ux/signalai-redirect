# signalai-redirect

Redirection de `signalai.fr` et `www.signalai.fr` vers `https://opportia.fr`, en conservant le chemin.

Ce dépôt a été créé le 15/10/2026 (S305.1), parce que la redirection web d'OVH ne sert pas le HTTPS. GitHub Pages fournit le certificat.

`404.html` est une copie de `index.html` : c'est ce qui permet de rediriger aussi les anciennes URL profondes (`/confidentialite`, etc.).

À conserver au moins jusqu'au 30/06/2027, fin de l'usage transitoire de SignalAi. Le domaine signalai.fr, lui, est conservé indéfiniment.
